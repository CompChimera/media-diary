# media-diary
App to track shame of half watched/read media. 

## Iterations of developments
### MVP
Using react and SQLite
- Add Media
    - Media Type
    - Media Source / Platform
    - Description
    - Completed
    - Repitions (multiple times read) (TODO: change to be list of dates)
- Display added media
- Remove / Archive Media
- Maybe: Export / Import Medias? (to build and export as a standalone page for people to use)
- Admin screen
    - Mange Platforms
    - Manage genres
    - Manage Types

### Second Iteration
- Switch to using an actual database and host on CC webspace.
- Hide Add Media page behind password protect
- Add list for suggested media
- Add genre tags (maybe look at AO3 for inspo on tags)
- Should tags have option to add a new one in the same form as adding tags? Or have a separate admin section for managing all the things (platforms, tags, etc)

### Third
- Add auth to have users? 
- Update all the media to be attached to a specific user. 
- Form would need to be updated to attach to the user that submits. 




### Stretch?
- APIs to different platforms?
